DEMO ACADÉMICA — VERIFICACIÓN
================================

La página reproduce la estructura visual de la referencia proporcionada,
pero está identificada como DEMO ACADÉMICA.

- documentos/constancia.jpg: imagen usada para la previsualización.
- datos.js: aquí puedes cambiar nombre, identificación, fecha y código.
- El botón DESCARGAR ORIGINAL (PDF) convierte la imagen JPG a PDF en el
  navegador. No hay ningún PDF almacenado en la carpeta.
- El botón QR abre el escáner. La cámara solo inicia al pulsar INICIAR CÁMARA.
- Para cámara se necesita HTTPS o localhost.


PDF: Para el botón de descarga, abre el proyecto con VS Code Live Server o cualquier servidor local. Esto evita las restricciones de fetch de file://.
